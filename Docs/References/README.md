# Reference images

Drop reference images for the Blender models here, one folder per category from `Docs/BlenderAssets.md`:

- `items/` (scrap and tools), `kit/` (doors, frames, lamps, pipes, stairs), `furniture/`, `exterior/` (wreck, boat, island), `characters/`.

Name each image after the asset id in the brief, for example `items/scrap_valve.png` or `exterior/ext_deck_crane.jpg`. Add `-2`, `-3` for more than one image of the same asset. Images for the overall style or mood can go in this folder as `style-*.png`.

The sizes in the brief take priority over a reference image. Images guide the shape, colour and detail.
